# SalonSync

**A Web-Based SaaS Management Platform for Salon Businesses**

## Student Information

- **Student Name:** Jennica Castillo
- **Course and Section:** ITE 311 - Web Systems and Technology 2, BSIT - 3F3

## Project Description

SalonSync is a web-based SaaS platform that helps salon businesses manage customers, services, appointments, staff, and transactions in one system. Salon businesses can subscribe to the platform and use its management tools to improve their daily operations.

## Technologies Used

- Laravel (PHP framework) - Back End
- CMS - Front End
- HTML and CSS
- SQLite / MySQL - Database
- Git and GitHub - Version Control
